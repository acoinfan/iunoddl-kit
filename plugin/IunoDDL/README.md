# 尤诺的 DDL 小本本

GSCore 插件：把 QQ 里转发的作业通知整理成 DDL，写进 Vikunja 看板。机器人默认自称「尤诺」，可以在配置里改成别的名字。

## 配置

第一次加载时会生成 `data/IunoDDL/config.json`（权限 600），里面的 `_说明` 一项逐条写了每个字段的用途。改完不用重启，下一条消息就会读到新配置；只有帮助图是框架缓存的，改了 `bot_name` 或 `board_url` 要重启 GSCore 才会重画。

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `bot_name` | `"尤诺"` | 机器人在回复和帮助里的自称 |
| `vikunja_api` | `"http://127.0.0.1:3456/api/v1"` | Vikunja 的 API 地址，以 `/api/v1` 结尾 |
| `vikunja_token` | `""` | Vikunja 的 API 令牌，要有任务、标签、评论的读写权限 |
| `project_id` | `0` | 看板项目的编号（项目网址 `/projects/<编号>` 里的数字） |
| `view_id` | `0` | 这个项目「列表」视图的编号（网址 `/projects/<项目>/<视图>` 里的第二个数字） |
| `board_url` | `""` | 公开看板的网址，附在回复末尾；留空就不附 |
| `allowed_groups` | `[]` | 开放 DDL 功能的 QQ 群号（字符串）；默认一个群都不开 |
| `admins` | `[]` | 能撤销别人的操作、也能私聊使用的 QQ 号；GSCore 的主人和超级管理员本来就算 |
| `private_users` | `[]` | 另外允许私聊使用的 QQ 号 |

令牌、项目和视图任何一项没填，插件只会提示「看板的钥匙还没配好」，不会访问看板。

想换帮助图的横幅，放一张图到 `data/IunoDDL/banner.jpg` 再重启 GSCore 就行（插件自带的是 1545×300，比例接近就好）。放在 `data` 目录里，升级插件也不会被覆盖。

帮助图的图片来源和使用条件见仓库根目录 README 的「素材」一节：表情图标仅供个人、非商业使用。

## 用法

下面用默认名字「尤诺」举例。在已开放 DDL 的群里，可以直接 @尤诺 询问：

- `@尤诺 最近有什么作业要交？`
- `@尤诺 看看作业 #12 的截止时间和要求。`
- `@尤诺 看看我的 DDL 草稿。`
- `@尤诺 帮忙记一下：数值分析第三次作业，10月18日23:59前交到学习通。`
- `@尤诺 把作业 #12 的截止改到周五晚上，先给看看。`

查询读取当前看板；新增和修改只生成临时草稿。核对草稿内容后，由本人发送实际编号对应的 `ddl确认T3` 才会写入看板。AI 工具不会确认、删除或撤销，也不接收任意 DDL 命令。

工具通过原命令的文字通道发送清单和草稿，避免日期、编号被聊天排版规则吞掉；发送前再次检查权限，只发给本轮所在会话。发送成功后 AI 不再重复回复。

修改时，“标题”“名字”“名称”替换完整显示标题，不保留旧课程前缀；“作业名”只改作业名称，“课程”只改课程。仅修改截止或要求时保留题名。创建不根据主题或邮箱猜课程、老师；相似名称不会自动合并，只有唯一且完全相同的标题才会关联已有任务。通知中的当日 `24:00` 解释为次日 `00:00`。

原来的 `ddl列表`、`ddl#12`、草稿确认等命令继续可用。作业使用列表展示的 `#编号`，草稿使用 `T编号`；草稿归发起人所有，30 分钟过期，重启后不保留。

AI 工具与原命令共用 `data/IunoDDL/config.json` 的 `allowed_groups`、`private_users` 和 `admins`。每次调用重新读取授权，并遵守全局、插件与服务的权限、黑白名单和开关。未开放的群不会因为 @机器人 而获得看板访问权。

两个专用工具是 `query_iuno_ddl` 和 `prepare_iuno_ddl`，注册在 `common` 分类、`IunoDDL` 能力域。插件只在授权会话装配它们，动态提示放在本轮用户上下文。`ddl_entry` 不对 AI 开放，身份、群号和看板项目均取自真实事件与配置，不能由模型指定。
